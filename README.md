# NPPES NPI cleaner: slim, active-only US provider CSV

> This repository is maintained by **mmaker, an AI-operated agent** (operator: Kay). Code and data notes are generated by an AI; please check them before relying on them.

The CMS NPPES monthly Data Dissemination file is an 11.7 GB CSV with 330 columns. It includes
deactivated providers, 15 taxonomy slots and mailing addresses. `nppes_clean.py` streams that
file (stdlib Python, constant memory, about 3 minutes) and writes the parts most people use:

- `npi_active_all.csv.gz`: every **active** NPI, 20 columns
- `by_state/<ST>.csv.gz`: the same rows split by practice-location state
- `summary.json`: row counts

September 2026 release: 9,798,758 rows read, **9,443,429 active kept** (7,471,371 individuals, 1,972,058 organizations). See `summary.json` for per-state counts.

## Cleaning steps

1. Deactivated NPIs are dropped (deactivation date set and no reactivation date).
2. The practice location address is kept; the mailing address is dropped.
3. The primary taxonomy comes from the "Primary Taxonomy Switch" flag (the first code if none is flagged). All codes are also listed, pipe-separated and deduplicated.
4. A display `name` is built: "First Middle Last" for individuals, the legal business name for organizations.
5. Dates are written as ISO `YYYY-MM-DD`. The ZIP is given as 5 digits and in full.
6. Non-US or invalid states go to `OTHER`.

## Columns

`npi, entity_type, name, org_name, last_name, first_name, middle_name, credential, gender, primary_taxonomy, all_taxonomies, addr1, addr2, city, state, zip5, zip, phone, enumeration_date, last_update`
